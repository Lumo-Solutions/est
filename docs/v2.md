## Phase 0 — Keycloak step-up

- Proved against the real stack that `auth_time` is the signal Keycloak 26 refreshes on an
  OTP-only step-up. All three freshness cases passed (login then step-up succeeds;
  step-up then expiry requires step-up again; a silent SSO re-authorize is not accepted
  as fresh silver). No freshness fix was needed.
- Fail-closed demo credential seeding: an unset or misspelled `APP_ENV` now refuses to
  seed known passwords/TOTP secrets, instead of seeding anyway.
- Fixed `completeMfaStepUp`, which filled a password field Keycloak never shows.
- Merged `fix/keycloak-step-up` to `master`.

## Phase 1 — Inventory and demo data

- `docs/ui-qa/coverage.md`: page × role × action matrix mapped to endpoints.
- Confirmed the no-UI capabilities: vendor master and duplicates, prequalification and
  certificates, cost library, Module E. Users and roles had no backend endpoint at all.
- New `make dev-seed-qa-demo-data` (rejected and lost settlements, a vendor duplicate
  pair, a vendor with expired / expiring / valid certificates); `dev-clean-demo-data`
  removes it.
- Fixed simulated `acr="silver"` contexts in `app/cli.py` that lacked `auth_time`
  (they broke `dev-simulate-*` after the step-up merge), with a static regression test.

## Phase 2 — Functional QA

**Frontend fixes (all P1)**
- No catch-all route: unmatched URLs rendered a blank page. Added `NotFoundPage`.
- React Query retried every 4xx three times, leaving pages on "Loading..." for 7-10s.
  Now only network errors and 5xx retry.
- `TakeoffViewerPage` showed "Loading..." forever on a real fetch error.
- Back links added on the project, sheet-index and takeoff pages.
- Missing client-side role gates and mutation error display, mirrored against each
  route's real server role list, on: Typology, ProcurementPackages, QuoteReview,
  Settlement (build/submit), WinLoss, all six Admin tabs; error display on Audit.
- Trade-node dropdown showed a raw Postgres ltree path instead of the name.
- Nav: removed `platform_admin` from the Admin/Audit links (it has no permissions on
  either); widened the Settlement link to the five roles the server already allows.

**Backend fixes**
- Completed the `JsonDecimal` sweep. Response fields on `QuotationOut`,
  `QuotationLineItemOut`, `QuotationExclusionFlagOut`, `BidLevelingCellOut`,
  `QuotationTotalOut` (and two Module E schemas) used bare `Decimal`, which serializes
  to a JSON string while the frontend types them `number`. Added a static test that
  scans every response schema so this cannot regress.
- Quarantine review queue showed every auto-processed email forever; it now also
  filters on `needs_review`.

**Not fixed, logged for later:** header shows the raw Keycloak UUID instead of a name;
`ProjectsListPage` pagination; money-format consistency beyond the new helper.

## Phase 3 — Gap-fill

- Vendor master, vendor detail (certificates with expiry badges, prequalification),
  duplicate review.
- Cost library and cost item detail (as-of-date rate view, record a new rate).
- Module E "Post-award" read views (contracts, BOQ revisions, exclusion register,

  FX-rate overrides.

  invented numbers.
- `formatMoney` helper in `frontend/src/lib/format.ts`.

**Real bugs found and fixed along the way**
- `acknowledge_exclusion_flag` never wrote an audit record.
- `taxonomy.update_node` / `move_node` crashed with `MissingGreenlet` (a 500 on every
  rename, toggle and move) because `updated_at` was never refreshed after the flush.
  Same bug in `boq.set_tolerance`'s update branch, found by a targeted sweep; reverted
  the fix once to confirm the new test fails without it.
- A cost-library "float precision" concern raised mid-run was a misdiagnosis: the
  columns are `NUMERIC` and values are real `Decimal` at runtime (verified against the
  live DB). Corrected in the log.

**Infrastructure**
- Keycloak: `installtec-backend` service account enabled with only `view-users`,
  `query-users`, `query-groups`; a client-role mapper on the `installtec-claims` scope
  (the admin API rejects the calls without it). Applied idempotently in
  `deploy/keycloak/bootstrap.sh`.
- `.mcp.json` sets `--ignore-https-errors` for the Playwright MCP server. It did not
  take effect within the session that added it; browser QA ran through the Playwright
  test runner instead. The Caddy dev CA was imported into the Windows trust store by
  you, not by me.

## Phase 4 — Design system (branch `phase-4-design-system`, not merged)

- `docs/ui-design-system.md`: tokens, components, layout targets, accessibility rules.
- Foundation: Tailwind v4 `@theme` tokens, self-hosted IBM Plex Sans via
  `@fontsource` (imported from `main.tsx`; a CSS `@import` had left the font files out
  of the build), shared `Badge`, `Spinner`, `Skeleton`, `@axe-core/playwright` dev
  dependency.
- `AppShell` converted from a top nav to a sidebar.
- Restyled: Projects list/detail, Sheet index, Takeoff viewer, Typology, BOQ import and
  reconciliation (AG Grid theme via the Theming API), Vendors (3 pages), Cost library
  (2), Procurement packages, Quarantine, Quote review, Bid leveling, Export, Win/loss,
  Admin (+ 6 tabs), Audit, Module E, Home dashboard, Settlement.
- Fixed while restyling: `VendorsPage` status filter offered "Suspended", which is not a
  real status (returned nothing); settlement line money always displayed as AED
  regardless of the settlement's currency; several missing error displays; an
  unlabeled file input; multiple axe contrast and label failures (`text-slate-400`,
  unnamed selects).
- Correction to the design doc itself: `text-success` as plain text measured 3.76:1
  under axe, not the 4.5:1 the doc claimed. The doc and the affected pages are fixed.
- Settlement Approve button uses the brand colour, not green (green fails AA as a
  white-text fill). A display-only "Verifying..." notice appears during the step-up
  redirect; the SoD gate and the step-up trigger are untouched.

- No cross-project "quotes to review / RFQs past due / settlements in draft" summary
  endpoint, so the dashboard is incomplete for estimators.
- Project member removal has no endpoint (add only).
- `CostRateComponentOut` / `CostItemRateOut` use `float` rather than `JsonDecimal`;
  identical JSON output, a tidiness item.

  few e2e tests skip.
- `NavLink` `end` prop: two nav items highlight together on drawing sub-pages.
- `BoqReconciliationPage` has a bare `text-success` on its Accept button that has not
  been exercised by an axe check.
- Dark theme not built (optional per the brief).
